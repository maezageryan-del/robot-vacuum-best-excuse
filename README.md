Entry for the [make.fun bounty "The Robot Vacuum's Best Excuse"](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214): one line, at most 140 characters, giving the funniest excuse a robot vacuum could offer for missing a spot.

## The entry

> I left that crumb as my alibi — the map says I cleaned twice, but nobody believes a vacuum with a spotless record.

114 characters, inside the 140-character gate. The vacuum plants one crumb as its alibi: its map log says it cleaned twice, and the punchline is the pun — a vacuum cannot afford a spotless record. Verified by running `main.py` twice from different directories: identical output both times.

## How it runs

`main.py` (Python 3.13) writes exactly that line to `/output/entry.txt`. It takes no input, makes no network calls, and always writes the same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
